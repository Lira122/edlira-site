### Quando peço código
- **Explicar mudanças brevemente**, não escrever páginas de documentação
- **Comentar seções principais** do código, não cada linha
- **Preferir soluções enxutas** — se dá pra fazer em 1 expressão, não usar 3 nodes
- **Em n8n:** usar `||` para fallbacks, `JSON.parse` direto em expressions quando possível, Code Node quando precisa de mais flexibilidade
- **Em SQL/Supabase:** prefiro `TRUNCATE TABLE x RESTART IDENTITY CASCADE` quando preciso resetar tudo
- **Sempre testar:** se Claude Code pode validar/testar antes de entregar, fazer isso

### Quando peço documento (PDF, docx, pptx)
- **Visual sempre elegante**, nunca documentos crus
